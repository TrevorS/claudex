# UI Views

This directory contains view implementations for different application states.

## Phase 2 Views

The following views will be implemented in Phase 2:

- **ListViewModel** - Browse conversations with sorting and scrolling
- **DetailViewModel** - Display full conversation with messages
- **SearchView** - Search interface with filter tags
- **StatsView** - Statistics and analytics dashboard
- **PaletteView** - Command palette for quick actions

See `docs/execution-plan.md` and `docs/ux-specs.md` for detailed specifications.
