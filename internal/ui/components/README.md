# UI Components

This directory contains reusable UI components built with Bubble Tea and Lipgloss.

## Phase 2 Components

The following components will be implemented in Phase 2:

- **Sidebar** - Project navigation and filtering
- **Header** - Current view title and metadata
- **StatusBar** - Keyboard hints and status messages
- **SearchBar** - Search input and filtering
- **List** - Scrollable conversation/message list
- **Modal** - Generic modal overlay for dialogs

See `docs/execution-plan.md` for implementation details.
